# Teknologjia dhe Kompjuteri

## Përshkrimi
Ky është një projekt edukativ për të mësuar rreth teknologjisë dhe kompjuterit.

## Qëllimi
Të mësojmë për pjesët kryesore të kompjuterit përmes një pyetjeje interaktive.

## Teknologjitë e përdorura
- HTML
- CSS
- JavaScript
- Replit
- GitHub

## Përdorimi i inteligjencës artificiale
Inteligjenca artificiale është përdorur si ndihmë gjatë krijimit të projektit.
